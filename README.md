# DI_Projeto_Final

Após a minha concepção do website no papel, eu comecei a trabalhar nele. Coloquei meu Led Zeppelin pra girar e comecei.

Inicialmente, eu comecei fazendo o início do HTML a mão, língua, doctype, fontes, até fiz um esboço de logo. 

Após terminar o <head>, eu comecei a fazer o CSS, inicialmente colocando as cores do root a mão, eu sabia que não iria fazer a gimmick de mudança de cores por gênero nessa versão, então selecionei um roxo que é bem usado.

Depois de fazer as cores, defini o border-box, e o scroll behavior, que eu tinha visto no CSS do último projeto que eu tinha feito da matéria. 

Após isso, eu utilizei ajuda da IA mencionada pra fazer uma logo temporária, e ajeitar o CSS do header, além de acertar o CSS do HTML que eu já tinha feito préviamente.

Depois foi essencialmente a repetição disso. Fazendo o HTML e CSS com a ajuda da IA, especialmente pra colocar essas frases de efeito, e ajudar com o nome das bandas e descrições.

Havia coisas que eu necessitei da IA para fazer, como a barra de pesquisa, e eventualmente parte da tela de acessibilidade e a tela de login.

Com isso dito, eu tinha visto muita coisa antes com os exercícios de bootstrap e CSS anyway. 

Espero conseguir transformar isso num site de verdade, imagino que vai ser bem útil.
